## Introduction

This guide demonstrates how to use the Skribble TypeScript SDK to interact with the Skribble API. We'll cover common operations such as creating signature requests, managing signers, handling documents, and more.

## Basic Setup

First, make sure you've installed and initialized the SDK as described in the [installation guide](installation).

```typescript
import skribble, { handleSkribbleError, Types, SkribbleAPIError } from 'skribble-sdk';

// Replace with your actual API credentials
const USERNAME: string = "api_xxxxx";
const API_KEY: string = "xxxxx";

async function main() {
  try {
    // Initialize the SDK
    await skribble.init(USERNAME, API_KEY);

    // Create a signature request
    const signatureRequest: Types.SignatureRequest = {
      title: "Test Signature Request",
      message: "Please sign this test document",
      file_url: "https://example.com/document.pdf",
      signatures: [
        {
          account_email: "signer@example.com",
          signer_identity_data: {
            email_address: "signer@example.com",
            first_name: "John",
            last_name: "Doe",
            language: "en"
          },
          sequence: 1,
        },
      ],
    };

    const response = await skribble.signature_request.create(signatureRequest);
    console.log("Signature request created successfully:", response);

    // Get the signature request
    const getResponse = await skribble.signature_request.get(response.id);
    console.log("Retrieved signature request:", getResponse);

  } catch (error) {
    const skribbleError = handleSkribbleError(error);
    console.error("An error occurred:", skribbleError.message);
    if (skribbleError instanceof SkribbleAPIError) {
      console.error("Status code:", skribbleError.statusCode);
      console.error("Response data:", skribbleError.responseData);
    }
  }
}

main();
```

## Checking Signature Request Status and Downloading Signed Document

After creating a signature request, you may want to check its status and download the signed document once it's completed. Here's how to do that:

```typescript
import * as fs from 'fs';

async function checkAndDownloadSignedDocument(signatureRequestId: string) {
  try {
    // Get the signature request details
    const signatureRequest = await skribble.signature_request.get(signatureRequestId);

    // Check if the signature request is signed
    if (signatureRequest.overall_status === 'SIGNED') {
      console.log("The signature request has been signed!");
      
      // Get the document ID
      const documentId = signatureRequest.document_id;
      
      // Download the signed document
      const signedDocument = await skribble.document.download(documentId);
      
      // Save the signed document to a file
      fs.writeFileSync("signed_document.pdf", signedDocument);
      
      console.log("Signed document downloaded and saved as 'signed_document.pdf'");
    } else {
      console.log(`The signature request is not yet signed. Current status: ${signatureRequest.overall_status}`);
    }
  } catch (error) {
    const skribbleError = handleSkribbleError(error);
    console.error("An error occurred:", skribbleError.message);
    if (skribbleError instanceof SkribbleAPIError) {
      console.error("Status code:", skribbleError.statusCode);
      console.error("Response data:", skribbleError.responseData);
    }
  }
}

// Usage
const signatureRequestId = "your_signature_request_id";
checkAndDownloadSignedDocument(signatureRequestId);
```

This code snippet demonstrates how to:

1. Retrieve the signature request details using `skribble.signature_request.get()`.
2. Check if the `overall_status` is 'SIGNED'.
3. If signed, get the `document_id` from the signature request.
4. Use `skribble.document.download()` to retrieve the signed document.
5. Save the downloaded document to a file using the `fs` module.

<Tip>
The `overall_status` can have different values such as 'OPEN', 'SIGNED', 'DECLINED', or 'WITHDRAWN'. Make sure to handle these different statuses in your application as needed.
</Tip>

You can periodically check the status of a signature request to determine when it has been signed and then proceed with downloading the signed document.
