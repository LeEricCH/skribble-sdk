## Introduction

This guide demonstrates how to use the Skribble Python SDK to interact with the Skribble API. We'll cover common operations such as creating signature requests, managing signers, handling documents, and more.

## Basic Setup

First, make sure you've installed and initialized the SDK as described in the [installation guide](installation).

```python
import skribble

# Replace with your actual API credentials
USERNAME = "your_username"
API_KEY = "your_api_key"

# Initialize the SDK
skribble.init(USERNAME, API_KEY)
```

## Signature Request Operations

### Creating a Signature Request

To create a signature request, use the following code:

<CodeGroup>

```python simple_signature_request.py
signature_request = {
    "title": "Test Signature Request",
    "message": "Please sign this test document",
    "file_url": "https://pdfobject.com/pdf/sample.pdf",
    "signatures": [
        {
            "account_email": "signer1@example.com"
        }
    ],
}

create_response = skribble.signature_request.create(signature_request)
print(create_response)
```


```python extended_signature_request.py
signature_request = {
    "title": "Test Signature Request",
    "message": "Please sign this test document",
    "content": "BASE64_ENCODED_DOCUMENT",
    "signatures": [
        {
            "account_email": "signer1@example.com",
            "signer_identity_data": {
                "email_address": "signer1@example.com",
                "mobile_number": "1234567890",
                "first_name": "John",
                "last_name": "Doe",
                "language": "en"
            },
            "sequence": 1,
        }
    ],
}

create_response = skribble.signature_request.create(signature_request)
print(create_response)
```

</CodeGroup>

You can either provide a `file_url` or a `document_id` or `content` to the `create` function. The `content` should be a base64 encoded string of the document.


### Adding a New Signer

To add a new signer to an existing signature request:

```python
new_signer_email = "newsigner@example.com"

add_signer_response = skribble.signature_request.add_signer(
    signature_request_id,
    email=new_signer_email,
    first_name="New",
    last_name="Signer",
    mobile_number="1234567890",
    language="en"
)
print("New signer added successfully:", add_signer_response)
```

<Tip>
You only need to provide the `email` parameter when adding a signer. The other parameters are optional.
</Tip>

### Removing a Signer

To remove a signer from an existing signature request you first need to get the signature request and then find the signer you want to remove and pass its `sid` to the `remove_signer` function.

```python
signature_request = skribble.signature_request.get(signature_request_id)

signer_to_remove = signature_request['signatures'][0] # This is the first signer in the list

skribble.signature_request.remove_signer(signature_request_id, signer_to_remove['sid'])

```

### Checking Signature Request Status and Downloading Signed Document

After creating a signature request, you may want to check its status and download the signed document once it's completed. Here's how to do that:

```python
# Get the signature request details
signature_request_id = "your_signature_request_id"
signature_request = skribble.signature_request.get(signature_request_id)

# Check if the signature request is signed
if signature_request['overall_status'] == 'SIGNED':
    print("The signature request has been signed!")
    
    # Get the document ID
    document_id = signature_request['document_id']
    
    # Download the signed document
    signed_document = skribble.document.download(document_id)
    
    # Save the signed document to a file
    with open("signed_document.pdf", "wb") as file:
        file.write(signed_document)
    
    print("Signed document downloaded and saved as 'signed_document.pdf'")
else:
    print(f"The signature request is not yet signed. Current status: {signature_request['overall_status']}")
```

This code snippet demonstrates how to:

1. Retrieve the signature request details using `skribble.signature_request.get()`.
2. Check if the `overall_status` is 'SIGNED'.
3. If signed, get the `document_id` from the signature request.
4. Use `skribble.document.download()` to retrieve the signed document.
5. Save the downloaded document to a file.

<Tip>
The `overall_status` can have different values such as 'OPEN', 'SIGNED', 'DECLINED', or 'WITHDRAWN'. Make sure to handle these different statuses in your application as needed.
</Tip>

You can periodically check the status of a signature request to determine when it has been signed and then proceed with downloading the signed document.
