# Working with Signature Requests

This guide shows you how to work with signature requests in common real-world scenarios. You'll learn best practices and see practical examples.

## Common Scenarios

### Sequential Signing Process

When you need multiple people to sign a document in a specific order:

```python
signature_request = {
    "title": "Board Resolution",
    "message": "Please review and sign the board resolution",
    "file_url": "https://example.com/board-resolution.pdf",
    "signatures": [
        {
            "account_email": "secretary@company.com",
            "sequence": 1,  # Signs first
            "signer_identity_data": {
                "first_name": "Jane",
                "last_name": "Smith",
                "email_address": "secretary@company.com"
            }
        },
        {
            "account_email": "ceo@company.com",
            "sequence": 2,  # Signs second
            "signer_identity_data": {
                "first_name": "John",
                "last_name": "Doe",
                "email_address": "ceo@company.com"
            }
        }
    ],
    "cc_email_addresses": ["legal@company.com"]  # Notified when complete
}

response = skribble.signature_request.create(signature_request)
```

### Bulk Contract Signing

When you need to send the same contract to multiple people for individual signing:

```python
def create_bulk_signature_requests(contract_url, signers):
    """
    Send the same contract to multiple signers.
    
    Args:
        contract_url (str): URL to the contract PDF
        signers (list): List of dicts with signer details
    """
    requests = []
    
    for signer in signers:
        signature_request = {
            "title": f"Service Agreement - {signer['name']}",
            "message": "Please review and sign your service agreement",
            "file_url": contract_url,
            "signatures": [
                {
                    "account_email": signer['email'],
                    "signer_identity_data": {
                        "first_name": signer['first_name'],
                        "last_name": signer['last_name'],
                        "email_address": signer['email']
                    }
                }
            ]
        }
        
        try:
            response = skribble.signature_request.create(signature_request)
            requests.append({
                "signer": signer['email'],
                "request_id": response['id']
            })
        except Exception as e:
            print(f"Error creating request for {signer['email']}: {str(e)}")
    
    return requests

# Example usage
signers = [
    {
        "name": "Alice Johnson",
        "first_name": "Alice",
        "last_name": "Johnson",
        "email": "alice@example.com"
    },
    {
        "name": "Bob Wilson",
        "first_name": "Bob",
        "last_name": "Wilson",
        "email": "bob@example.com"
    }
]

results = create_bulk_signature_requests(
    "https://example.com/service-agreement.pdf",
    signers
)
```

## Best Practices

### Error Handling

Implement robust error handling for your signature requests:

```python
def create_signature_request_safely(request_data):
    """
    Create a signature request with proper error handling.
    """
    try:
        response = skribble.signature_request.create(request_data)
        return {
            "success": True,
            "request_id": response['id']
        }
        
    except SkribbleAPIError as e:
        if e.status_code == 400:
            # Handle validation errors
            return {
                "success": False,
                "error": "Invalid request data",
                "details": e.response_data
            }
        elif e.status_code == 401:
            # Handle authentication errors
            return {
                "success": False,
                "error": "Authentication failed"
            }
        else:
            # Handle other API errors
            return {
                "success": False,
                "error": f"API error: {e.message}"
            }
            
    except SkribbleError as e:
        # Handle client-side errors
        return {
            "success": False,
            "error": f"Client error: {str(e)}"
        }
        
    except Exception as e:
        # Handle unexpected errors
        return {
            "success": False,
            "error": f"Unexpected error: {str(e)}"
        }
```

### Document Management

Properly manage documents before creating signature requests:

```python
def prepare_document_for_signing(file_path):
    """
    Prepare a document for signing by uploading it first.
    """
    try:
        # Read the file
        with open(file_path, 'rb') as f:
            content = f.read()
        
        # Convert to base64
        import base64
        content_base64 = base64.b64encode(content).decode('utf-8')
        
        # Create document request
        document_request = {
            "title": os.path.basename(file_path),
            "content": content_base64,
            "content_type": "application/pdf"
        }
        
        # Create the document
        document = skribble.document.create(document_request)
        
        return document['id']
        
    except Exception as e:
        print(f"Error preparing document: {str(e)}")
        return None
```
